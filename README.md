# Aref Jalali — Night Drive

Personal portfolio for video editing, motion design and AI video production. Persian, English and German, with local Yekan Bakh fonts, original portraits, scroll-driven motorcycle animation, neon rain and resume-based infographics.

Live website: https://thearefworksarmenia-dev.github.io/arefjalali.github.io/?lang=fa

GitHub Pages publishes `main` / root. The site is static and requires no build, API keys or external runtime. `.nojekyll` preserves the static assets.

## Editing

- `index.html`: structure.
- `content.js`: language copy and STUDIO_PROJECTS. Use genuine project links and en/fa/de descriptions.
- `resume-content.js`: current resume facts and new sections.
- `cinematic.css` and `night-drive.css`: layout, local fonts and appearance.
- `studio.js`: languages, filters, project dialogs and original scroll scenes.
- `night-drive.js`: three rendered motorcycle views, rain, smoke, neon trail and infographic motion. These are 2.5D views, not a real 3D model.
- `assets/`: supplied images, fonts and downloadable professional resume.

Push changes to main and wait for the GitHub Pages deployment. Test all three languages, keyboard controls, pause motion, mobile layout, resume link and project dialogs after edits. See NIGHT-DRIVE-DESIGN.md for visual direction and asset provenance.

Earlier website versions remain in Git history. No Sites credentials or internal hosting identity are included.
